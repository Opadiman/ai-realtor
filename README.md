# ИИ Риелтор

Лендинг ИИ-помощника для аренды недвижимости.

Статический сайт: HTML, CSS, JavaScript. Сборка не требуется.
Для GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).

Демонстрация диалога, согласования и отмены встречи работает только в браузере.
Скриншоты кабинета содержат вымышленные данные. Интеграция Авито в разработке.

Шрифт Manrope распространяется по SIL Open Font License, текст лицензии в assets/Manrope-LICENSE.txt.
Архитектурное изображение создано с помощью ImageGen.
